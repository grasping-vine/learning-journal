## 指针学习总结

---

### 一、指针是什么

```c
int *p;
```

- **`p` 是指针**，里面存的是地址
- **`p` 的值是地址**，比如 `0x16b1a2f3c`
- **`*p` 是变量**，就是那个地址里存的东西

**一句话：`p` 是地址，`*p` 是变量。**

---

### 二、`&` 和 `*`

| 运算符 | 后面必须接 | 结果 |
|--------|-----------|------|
| `&` | 变量 | 这个变量的地址 |
| `*` | 地址/指针 | 这个地址里存的东西 |

**恒等式**：

```c
*&x == x      // 先取地址，再解引用，回到变量
&*p == p      // 先解引用，再取地址，回到指针
```

**注意**：`*&x` 和 `&*x` 不可能同时合法，因为 `x` 不可能同时是普通变量和指针。

---

### 三、星号什么时候是定义，什么时候是解引用

| 场景 | 星号含义 | 例子 |
|------|---------|------|
| **声明时** | 定义指针 | `int *p;` |
| **使用时** | 解引用 | `*p = 10;` |

**判断方法**：看星号前面有没有类型名。有类型名 → 声明；没有 → 解引用。

---

### 四、数组和指针

```c
int arr[5] = {10, 20, 30, 40, 50};
```

- `arr` 是**数组首元素的地址**，是常量
- `arr[i]` 是**第 i 个元素的值**，是变量
- `arr[i] == *(arr + i)`

**推导链条**：

1. `arr` 是首元素地址
2. `arr + i` 是从首元素往后走 i 个元素的地址
3. `*(arr + i)` 是走到那个地址后，把里面的值取出来
4. `arr[i]` 就是它的简写

**冷知识**：`i[arr]` 也合法，因为 `*(i + arr)` 和 `*(arr + i)` 一样。

---

### 五、指针的类型

```c
int *p;     // 指向 int 的指针
char *p;    // 指向 char 的指针
```

- `int` 修饰的是 `*p`，不是 `p`
- 指针的类型决定了“解引用时按什么格式读内存”
- 也决定了“`p + 1` 走多远”

**同一个地址，用 `int *` 读和用 `char *` 读，结果不同。**

---

### 六、野指针、悬空指针、空指针

| 指针 | 状态 | 能安全判断吗 |
|------|------|-------------|
| 野指针 | 没初始化，垃圾值 | ❌ |
| 悬空指针 | 曾经有效，内存已释放 | ❌ |
| 空指针 | 明确指向 `NULL` | ✅ |

**空指针的用途**：

1. 表示“没找到”
2. 释放后置空，防止悬空
3. 初始化时置空，避免野指针
4. 链表结尾（以后学）

**核心**：空指针不是永久报废，它只是“当前不指向任何东西”，随时可以重新赋值为有效地址。

---

### 七、指针的安全习惯

```c
// 创建时初始化
int *p = NULL;

// 申请内存后检查
p = malloc(sizeof(int));
if (p == NULL) {
    return;
}

// 使用
*p = 100;

// 释放后置空
free(p);
p = NULL;
```

**核心原则**：指针创建时置 `NULL`，释放后置 `NULL`。两步都做，才叫完整。

---

### 八、字符串和数组的关系

- C 语言没有字符串类型，字符串就是**以 `\0` 结尾的字符数组**
- `str` 是字符数组首元素的地址
- `str[i] == *(str + i)`
- `%s` 从地址开始打印到 `\0`

---

### 九、一句话总结

> 指针就是存地址的变量。`p` 是地址，`*p` 是变量。数组名是首元素地址，`arr[i]` 就是 `*(arr + i)`。指针创建时置 `NULL`，释放后置 `NULL`，保证它在无效期里安全可控。
