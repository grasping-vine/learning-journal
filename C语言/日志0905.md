## 今日学习总结：C 语言入门与指针初探

---

### 一、基本输入输出

#### `printf` 格式占位符

| 占位符 | 含义 | 对应类型 |
|--------|------|---------|
| `%d` | 十进制整数 | `int` |
| `%c` | 单个字符 | `char` |
| `%f` | 浮点数 | `float` / `double` |
| `%s` | 字符串 | `char[]` |
| `%x` | 十六进制整数 | `int` |
| `%p` | 指针地址 | 任意指针 |
| `%%` | 百分号本身 | 无 |

**核心理解**：`printf` 是一个填空游戏。引号里的 `%d` 是空位，后面的参数按顺序对号入座。

**数量必须匹配，类型必须匹配。**

---

#### `scanf` 与 `&` 的关系

```c
int age;
scanf("%d", &age);
```

- `%d`：期待从键盘读一个十进制整数
- `&age`：把读到的值存到 `age` 的内存位置
- `printf` 读值不需要 `&`，`scanf` 写入需要知道地址

**规律**：
- 普通变量 → 必须加 `&`
- 数组名 → 不加 `&`（数组名本身就是地址）
- 指针变量 → 不加 `&`（指针里存的已经是地址）

---

#### `scanf` 的空白字符陷阱

```c
scanf("%d", &age);
scanf("%c", &ch);   // 会直接读到回车符！
```

输入 `18\n` 后，`%d` 读走 `18`，但 `\n` 留在缓冲区，被 `%c` 直接读走。

**解决办法**：`%c` 前加空格

```c
scanf(" %c", &ch);   // 跳过任意空白字符后再读
```

**核心理解**：`scanf` 格式串里的空白字符（空格、`\n`、`\t`）是“跳过空白”的指令，不是“匹配一个空白”。

---

#### `scanf` 格式串里的普通字符

```c
scanf("%d:%d", &hour, &minute);
```

格式串里的 `:` 要求用户**原样输入**。

| 格式串里的内容 | 作用 |
|--------------|------|
| 空白字符 | 跳过输入里的任意空白 |
| `%` 开头 | 读取对应类型数据 |
| 其他普通字符 | 要求原样输入 |

---

#### `%d` 后面写 `\n` 是坑

```c
scanf("%d\n", &age);   // 会卡住！
```

因为 `\n` 会跳过所有空白直到遇到非空白字符，导致程序等你多输入一个东西。

**初学阶段不要写 `scanf("%d\n", ...)`。**

### 二、数组与指针

#### 数组名是地址常量

```c
int arr[5];
arr = 任何东西;   // 永远错误
```

数组名是**首元素的地址**，是常量，不能被赋值。

**规则**：数组名不带方括号，后面直接接 `=`，必定错误。

---

#### `arr[2]` 的本质

```c
arr[2]  ==  *(arr + 2)
```

数组下标运算本质是指针运算：

1. `arr` 是首元素地址
2. `arr + 2` 往后走 2 个元素
3. `*(arr + 2)` 取出那个位置的值

**冷知识**：`2[arr]` 也合法，因为 `*(2 + arr)` 和 `*(arr + 2)` 一样。但正常人不会这么写。

---

#### 指针核心三句话

```c
int *p;
```

- **`p` 是指针**，里面存的是地址
- **`p` 的值是地址**，比如 `0x16b1a2f3c`
- **`*p` 是变量**，就是那个地址里存的东西

**一句话**：`p` 是地址，`*p` 是变量。

---

#### 星号和取地址符

| 运算符 | 后面必须接 | 结果 |
|--------|-----------|------|
| `&` | 变量 | 这个变量的地址 |
| `*` | 地址/指针 | 这个地址里存的东西 |

**恒等式**：

```c
*&x == x      // 先取地址，再解引用，回到变量
&*p == p      // 先解引用，再取地址，回到指针
```

**注意**：`*&x` 和 `&*x` 不可能同时合法，因为 `x` 不可能同时是普通变量和指针。

### 三、函数与格式风格

#### 函数声明各部分

```c
int add(int a, int b)
↑     ↑
返回类型  参数类型
```

- 函数名**前面**的类型是返回类型
- 括号**里面**的类型是参数类型
- `return` 后面的值必须和返回类型匹配

---

#### `main` 函数

```c
int main(void) {
    return 0;
}
```

- C 语言标准规定 `main` 必须返回 `int`
- 返回 `0` 表示程序正常结束
- `return;` 只适合 `void` 函数，`main` 不该是 `void`

---

#### 代码风格

| 风格 | 特点 | 常见语言 |
|------|------|---------|
| K&R | `{` 跟在语句后面 | C、C++、Java |
| Allman | `{` 单独占一行 | C# |

**K&R 转换规则**：把 Allman 的每个左花括号前的换行去掉，`} else {` 合成一行。

初学阶段：选一种，保持一致。C 语言推荐 K&R。
